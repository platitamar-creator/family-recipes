# 📖 ספר המתכונים המשפחתי

אתר חמים לשמירת כל המתכונים של המשפחה. מחולק ל"בתים", ושיתוף נעשה בקישורים, בלי הרשמה.

## איך זה בנוי

| חלק | טכנולוגיה |
|---|---|
| האתר | HTML, Tailwind CSS ו-JavaScript רגיל, בלי שלב בנייה חוץ מה-CSS |
| מסד נתונים | פרויקט Supabase נפרד בשם `family-recipes` |
| תמונות | Supabase Storage (התיקייה `recipe-images`). התמונות מוקטנות בדפדפן לפני ההעלאה |
| אחסון האתר | GitHub Pages |

### אבטחה
- הטבלאות יושבות ב-schema פרטי בשם `app`, שהדפדפן לא יכול לגשת אליו.
- כל קריאה וכתיבה עוברות דרך פונקציות ב-`public` (ראו `supabase/migrations/002_functions.sql`), וכל פונקציה בודקת את הקוד שהיא מקבלת:
  - **מפתח מכשיר** של בן בית: גישה מלאה לבית שלו.
  - **קוד צפייה בבית**: קריאה בלבד, ואפשר להוסיף הערות ו"אפשרויות לשינוי".
  - **קוד צפייה במתכון**: אותו דבר, אבל רק למתכון אחד.
- העלאת תמונות עוברת דרך פונקציית השרת `supabase/functions/images`, שמנפיקה כתובת העלאה חתומה רק לבני בית.

### אפליקציה בטלפון
- `manifest.webmanifest` והאייקונים ב-`icons/` מאפשרים "הוספה למסך הבית" (באנדרואיד מופיע כפתור התקנה, באייפון יש הוראות בדף הבית).
- `sw.js` שומר את קבצי האתר ואת תמונות המתכונים במכשיר, כך שהאפליקציה נפתחת מהר וגם בלי רשת. כשמוסיפים קובץ JS חדש, צריך להוסיף אותו לרשימה `SHELL_FILES` ב-`sw.js` ולהעלות את `VERSION`.
- באייפון, אפליקציה שנוספה למסך הבית לא משתפת את הזיכרון עם Safari. לכן בדף הבית יש תיבה "קיבלת קישור?" להדבקת קישור ההצטרפות.

### "הכנתי!" וציר הזמן
- בדף מתכון, בן בית לוחץ "הכנתי!" ובוחר תאריך, מי בישל והערה. ההכנות נשמרות בטבלה `app.cook_log` (ראו `supabase/migrations/004_cook_log.sql`).
- המסך "מה בישלנו" (`#/h/<בית>/timeline`) מציג את כל הבית, מתכון אחד או השוואה בין עד 4 מתכונים.

### קישורים
- `#/join/<קוד>`: הצטרפות לבית
- `#/v/<קוד>`: צפייה בבית
- `#/r/<קוד>`: צפייה במתכון בודד

## עבודה על הקוד

```bash
npm install
npm run watch:css     # בונה מחדש את css/app.css בכל שינוי
python3 -m http.server 8000
```

אחרי שינוי של מחלקות Tailwind צריך להריץ `npm run build:css` ולשמור את `css/app.css` במאגר, כי GitHub Pages מגיש את הקבצים כמו שהם.

## מבנה הקבצים

```
index.html
css/input.css         מקור העיצוב (צבעים, כפתורים, כרטיסים)
css/app.css           הקובץ הבנוי (לא לערוך ידנית)
js/app.js             ניתוב בין המסכים
js/api.js             חיבור ל-Supabase
js/store.js           מה שנשמר במכשיר (מפתחות, סימוני רשימת קניות)
js/quotes.js          הציטוטים היומיים
js/images.js          הקטנה והעלאה של תמונות
js/views/*.js         המסכים
js/install.js         התקנה כאפליקציה
js/decor.js           איורים, אנימציות וקונפטי
img/doodles.svg       ציורי הרקע
sw.js                 עבודה מהירה ובלי רשת
supabase/             הגדרות מסד הנתונים ופונקציית התמונות
```
